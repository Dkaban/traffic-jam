# Traffic Jam

A little living city where the roads are yours to design.

Draw streets, add homes and businesses, and watch vehicles find their way across the neighborhood. As your city grows, traffic grows with it. Rework your network using signals, stop signs, fast lanes, one-way streets, and roundabouts to keep things moving.

## Play

Open the GitHub Pages site, or run a local web server from the repository root. For example, `npm run start`, then visit `http://localhost:8080`.

Draw roads by dragging; place buildings beside them. Select road controls and click existing road tiles to modify them. Zoom with the mouse wheel and pan with right-drag or Space + drag. Use the built-in guide for controls and shortcuts.

The map saves automatically in your browser. No accounts or API keys are required.

## Development

Built with JavaScript, HTML Canvas, and CSS. There are no runtime dependencies or build steps.

Run `npm test` for simulation smoke tests.
